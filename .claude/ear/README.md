# أدوات السمع

Claude لا يسمع الصوت مباشرة؛ هذه الأدوات تحوّله إلى نص وأرقام يقرؤها. تُثبَّت تلقائياً عند بدء كل جلسة سحابية (`.claude/hooks/ear-setup.sh`، السجل في `/tmp/ear-setup.log`).

| الأداة | الاستعمال | ماذا تعطي |
|---|---|---|
| `hear.py` | `python3 .claude/ear/hear.py ملف` | نص الكلام مع توقيت كل كلمة (نموذج ويسبر large-v3-turbo؛ يُنزَّل عند أول تشغيل) |
| `cmp.py` | `from cmp import diff; diff(النص_المعتمد, التفريغ)` | عدد الكلمات المختلفة وقائمتها |
| `card.py` | `python3 .claude/ear/card.py ملف [--no-speech]` | بطاقة الصوت: المدة، العلو، الوقفات، أعلى اللحظات، طبقة الصوت، الإيقاع، سرعة الكلام |
| `ear.py` | `ear.ipa(ملف, من, إلى)` | الرموز الصوتية لمقطع محدد (للتحقق من نطق كلمة) |
| `asr.py` | `asr.txt(ملف, من, إلى)` | تفريغ حرفي بنموذج عربي أقدم (أذن ثانية) |
| `align.py` | `python3 .claude/ear/align.py صوت "النص" خرج.wav` | توقيت كل كلمة من نص معروف |

الثلاث الأخيرة تحتاج الأدوات الثقيلة: `bash .claude/hooks/ear-setup.sh full` ثم انتظر `/tmp/ear-setup.log`.

## طريقة العمل
1. كل تعليق صوتي جديد يُفرَّغ كاملاً بـ`hear.py` ويُقارَن بالنص المعتمد بـ`cmp.py` قبل المونتاج.
2. كل كلمة مختلفة تُفحص بـ`ear.py`؛ إن اتفق نموذجان على الخطأ يُعاد توليد الجملة.
3. كل صوت رائج أو موسيقى يُعمل له بطاقة صوت بـ`card.py` قبل اختياره.

## الحدود
- لا تلتقط النبرة (ساخر، حزين، مضحك) ولا «جوّ» الموسيقى؛ الحكم فيها لصاحب المشروع.
- توقيت أول كلمة في ويسبر غير دقيق إذا بدأت الموسيقى قبل الكلام.
- قياس 21 نوفمبر 2026 على تسجيل «قصة صُب» (262 كلمة): ويسبر 29 كلمة مختلفة (11.1%)، النموذج الأقدم 178 (67.9%).
